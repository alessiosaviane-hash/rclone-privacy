
# Rclone – Personal Synchronization

This website describes a personal installation of Rclone running on Ubuntu Linux.

Rclone is an open-source software used by the owner of this installation to synchronize selected folders between a local computer and the owner's Google Drive account.

The synchronization is performed directly between the local computer and Google Drive using Google's official APIs and OAuth 2.0 authorization.

This is a private, single-user installation. It is not a commercial service and is not offered to third parties.

The configured synchronization concerns selected folders, including Documents, Images and Videos, together with their backup copies.

GitHub Pages is used exclusively to host these informational pages. No Google Drive files, credentials or synchronization data are uploaded to GitHub.
